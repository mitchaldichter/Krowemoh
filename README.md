# Krowemoh
This is Krowemoh, which is just homework spelled backwards.

Krowemoh's inspiration is [WeBWorK](https://openwebwork.org/) and is meant to be an easy way to include exercises on webpages.

### Exercise Attribution
There should be an HTML &lt;details&gt; element at the bottom of each exercise that is sufficient for attribution. Please inform me if there is no HTML &lt;details&gt; element for an exercise.

For original works, the HTML &lt;details&gt; element should be similar to the below template.
```html
<details>
  <summary>Attribution and License</summary>
  Title of Work: <br>
  Author: <br>
  Source: <br>
  License: <a href="https://creativecommons.org/licenses/by-sa/4.0/deed.en" target="_blank" class="Krowemoh_anchor">CC BY-SA 4.0</a>
</details>
```

For derivative works, the HTML &lt;details&gt; element should be similar to the below template.
```html
<details>
  <summary>Attribution and License</summary>
  Title of Original Work: <br>
  Original Author: <br>
  Original Source: <br>
  License: CC BY-SA 4.0 https://creativecommons.org/licenses/by-sa/4.0/deed.en<br>
  <br>
  Title of Derivative Work: <br>
  Derivative Author: <br>
  Derivative Source: <br>
  License: CC BY-SA 4.0 https://creativecommons.org/licenses/by-sa/4.0/deed.en
</details>
```
